# Power-PVP-Toggler
A simple plugin that allows users to personally disable and enable pvp per player. 

Each user can run command 
/pvp <on|off>  

pvp on: Can recieve and give damage to other players  

pvp off: cannot recieve or give damage to other players.  



Permisisons:  
  strawberry_pvp_plugin.command.pvp: 
    default true
